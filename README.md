# 智能文本检测与格式批注系统

## 📖 项目简介

本项目融合**NLP文本检测**与**计算机视觉（CV）技术**，开发面向学生论文/报告的智能校验工具，核心解决学术文书排版不规范、人工校对效率低的痛点，实现错别字、语法错误、参考文献格式违规、图片编号不规范等问题的自动识别、批注与一键修正。

### 项目定位

面向论文、实验报告、课程设计文档等学术文本，自动完成**错别字检测、语法错误识别、参考文献规范检查、图片/表格编号校验、版式问题提示、批注生成与修正建议输出**，提升学生学术写作与排版效率。

### 目标用户

- 本科生 / 研究生
- 教师审阅论文、作业
- 教务/实验课程文档规范检查

### 核心价值

解决传统人工检查中的**低效率、易遗漏、规范标准难统一、修改建议不明确**等问题。

## ✨ 核心功能

### 1️⃣ 基础文本智能检测（NLP核心）

- **错别字识别**：精准识别中文文本中的错别字，支持常见错字、易混淆字（如"按装-安装""错别子-错别字"）检测
- **语法错误定位**：识别语句不通顺、搭配不当、标点使用错误等语法问题，支持上下文语义校验
- **批量检测能力**：支持遍历文档全文、段落、表格内所有文本，覆盖不同文本区域的检测需求

### 2️⃣ 参考文献格式专项校验

- **格式规范基准**：严格遵循**GB/T 7714-2015《信息与文献 参考文献著录规则》**，覆盖期刊、学位论文、图书、网络资源等主流文献类型
- **自动定位识别**：精准提取文档末尾"参考文献"章节内容，区分不同文献类型
- **多维度合规校验**：
  - 字段完整性：检查作者、年份、刊名、页码、出版社等核心字段是否缺失
  - 格式规范性：校验标点符号、著录顺序、大小写等是否符合国标要求
  - 重复/错误识别：排查重复引用、格式混乱等问题
- **违规批注提示**：对格式违规条目自动标注，明确违反的规范条款及标准修正示例

### 3️⃣ 图片/图表格式校验（CV核心）

- **图片定位提取**：提取Word/PDF文档内嵌的所有图片、表格，识别其位置与关联区域
- **编号规范检测**：校验图号（如"图1-1""图2.3"）、表号是否符合学术排版规范（如编号层级统一、无跳号/重复）
- **图文匹配校验**：检查正文引用的图号/表号与图片/表格下方标注的编号是否一致，避免图文对应错误
- **排版合理性检查**：初步判断图片/表格排版位置是否符合学术文档常规要求

### 4️⃣ 自动批注与一键修正

- **智能批注生成**：针对检测到的所有问题，自动在文档对应位置插入原生批注，标注问题类型、原因及修正建议
- **一键批量修正**：支持对可自动修复的问题进行批量修正，生成排版规范的新文档
- **修正报告输出**：统计问题类型、数量、整改完成率，生成明细化校验报告（支持导出TXT/Excel格式）

### 功能模块设计

#### 模块1：错别字与语法错误检测

**技术方案 - 两阶段方案**：

| 方案 | 技术选型 | 说明 |
|-----|---------|------|
| 基础版 | pycorrector + language_tool_python | 稳定可控，适合快速实现 |
| 进阶版 | MacBERT / BERT / RoBERTa-wwm-ext | 序列标注或纠错，更"智能" |

**自建学术词典**：
- 专业词汇白名单
- 常见错词库
- 学术固定表达模板

**输出示例**：
```
原文：本文对算法进行乐深入研究。

系统提示：
- 错误类型：疑似错别字
- 位置：第 3 段第 12 字
- 建议："乐" → "了"
- 说明：上下文语义不通顺
```

#### 模块2：参考文献格式检查（重点亮点）

依据 **GB/T 7714** 检查：

- [J] 期刊 / [M] 专著 / [D] 学位论文 / [C] 论文集 / [N] 报纸 / [R] 报告 / [EB/OL] 电子文献
- 作者格式、中英文标点、编号连续性
- 文中引用与文末参考文献一致性

**实现方式**：正则表达式 + 文献类型模板 + 规则引擎

**输出示例**：
```
原文献：
[3] 张三.人工智能导论.北京:清华大学出版社 2023

系统批注：
- 问题1：缺少文献类型标识 [M]
- 问题2：出版社与年份之间缺少逗号
- 修正建议：[3] 张三. 人工智能导论[M]. 北京: 清华大学出版社, 2023.
```

#### 模块3：图片编号与图题检测

| 实现思路 | 适用场景 | 技术方案 |
|---------|---------|---------|
| 结构化解析 | docx文档 | python-docx解析段落、图片顺序 |
| 版面分析 | PDF/扫描文档 | PaddleOCR + PP-Structure |

**检测内容**：
- 图编号连续性（图1、图3缺少图2）
- 图题格式一致性（"图1"与"Fig.2"混用）
- 图题位置正确性（应在图下方）
- 表题位置正确性（一般在表上方）
- 图表是否被正文引用

#### 模块4：批注生成与一键修正

**输出形式**：
1. 网页端展示问题列表
2. 生成带批注的 docx / pdf
3. 导出审校报告 .html / .pdf

**错误数据结构**：
```json
{
  "type": "reference_format_error",
  "location": "参考文献[5]",
  "original": "[5] 李四.深度学习应用. 2023",
  "suggestion": "[5] 李四. 深度学习应用[M]. 北京: xx出版社, 2023.",
  "level": "medium",
  "auto_fix": true
}
```

## 📊 系统流程设计

```
用户上传文档 → 文档解析模块提取结构化内容 → 文本内容进入NLP检测模块
     ↓
参考文献与编号进入规则校验模块 → 页面布局进入CV/版面检测模块
     ↓
汇总错误信息 → 生成批注与修正建议 → 输出审校结果和修正版文档
```

## ⚠️ 技术难点与解决方案

| 难点 | 解决方案 |
|-----|---------|
| 中文语法纠错准确率不稳定 | 规则+词典+模型联合判断，高风险修正做人工确认 |
| GB/T 7714 实际格式复杂 | 先支持期刊[M]、专著[J]、学位论文[D]、会议论文[C] |
| PDF 版面解析难 | 先支持docx，PDF作为扩展功能，分阶段实现 |
| 一键修正容易误改 | 只对高置信度错误开放自动修复，低置信度只做建议 |
