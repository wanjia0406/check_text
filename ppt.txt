## 幻灯片3：项目背景

### 研究背景
- 学术论文写作中存在大量格式规范问题
- 人工校对效率低、成本高、易出错
- 现有工具功能单一，难以满足综合需求

### 问题分析
| 问题类型 | 常见问题 | 影响 |
|---------|---------|------|
| 错别字 | 形近字、同音字错误 | 影响专业性 |
| 语法错误 | 成分残缺、句式杂糅 | 影响可读性 |
| 参考文献 | 格式不规范、编号错误 | 影响学术严谨性 |
| 图表编号 | 编号不连续、引用错误 | 影响结构完整性 |

### 项目目标
- 开发智能化学术文档校验工具
- 实现多维度自动检测与批注
- 提供一键修正建议功能

```

├─────────────────────────────────────────────────────┤

│  │  错别字  │  │  语法检测│  │ 语义分析 │          │

│       │             │             │                 │
```

### 功能模块详解

**1. 错别字识别模块**
- 双模型结构：macbert_finetuned + pycorrector
- 深度学习+规则引擎融合
- 支持学术领域专业术语保护
- ✅ 测试验证：准确率92.5%，召回率85.6%，F1值88.9%

**2. 语法检测模块**
- 成分残缺检测（缺主语、缺谓语等）
- 句式杂糅检测
- 语义重复检测
- 关联词错误检测
- ✅ 测试验证：准确率83.4%，召回率41.5%，F1值55.8%

**3. 参考文献校验模块**
- 支持GB/T 7714规范
- 多种文献类型识别：期刊[J]、专著[M]、学位论文[D]等
- 自动格式修正建议
- ✅ 测试验证：准确率75.6%，召回率88.9%，F1值81.7%

**4. 语义分析模块**
- 语义重复检测
- 逻辑矛盾检测
- 学术表达规范检测
- ✅ 测试验证：准确率86.7%，召回率62.3%，F1值72.8%

**5. 图表检测模块**
- 图片编号连续性检测
- 表格编号规范性检测
- 图片OCR识别与纠错
- Word文档图片提取
- PDF文档图片OCR处理

**6. 多格式文档支持**
- Word文档（.docx）：完整处理，保留图片和表格
- PDF文档：文本提取、图片OCR、表格提取
- 图片文件（.png, .jpg等）：OCR识别并纠错

## 幻灯片6：关键技术实现 - 双模型纠错机制

### 模型架构
```
                    输入文本
                        │
                        ▼
        ┌───────────────────────────────┐
        │       错误映射表修正          │
        │  (常见错误词预定义替换)        │
        └───────────────┬───────────────┘
                        │
            ┌───────────┴───────────┐
            ▼                       ▼
    ┌─────────────┐         ┌─────────────┐
    │ macbert模型 │         │pycorrector  │
    │ (深度学习)  │         │ (规则引擎)  │
    └────┬───────┘         └────┬───────┘
         │                     │
         └───────────┬───────────┘
                     ▼
              投票融合机制
                     │
                     ▼
              保护术语过滤
                     │
                     ▼
              最终纠错结果
```

### 纠错流程
1. **错误映射表预处理**：对常见错误词进行预定义替换
2. **macbert模型检测**：基于深度学习的细粒度错别字检测
3. **pycorrector规则检测**：基于规则引擎的文本纠错
4. **投票融合**：综合两个模型的检测结果
5. **术语保护**：过滤专业术语，避免误改

### 保护机制
- 专业术语保护列表（150+学术术语）
- 单字保护（标点符号、常用虚词）
- Emoji保护
- 位置敏感保护（避免破坏保护术语）

## 幻灯片8：关键技术实现 - 语法检测引擎

### 语病类型覆盖
| 语病类型 | 检测规则 | 示例 |
|---------|---------|------|
| 成分残缺 | "通过...使..."结构 | 通过实验，使我们发现... |
| 句式杂糅 | "目的是为了..." | 目的是为了解决问题 |
| 语义重复 | "十分显著明显" | 效果十分显著明显 |
| 关联词错误 | "只要...才能..." | 只要努力，才能成功 |
| 搭配不当 | "改善坏习惯" | 改善学生坏习惯 |
| 逻辑不通 | 前后矛盾表达 | 提高速度同时降低效率 |

### 检测流程
1. **规则匹配**：基于正则表达式的模式匹配
2. **结构分析**：句子结构深度分析
3. **学术表达检测**：第一人称、口语化表达检测
4. **语义分析**：逻辑关系与搭配分析

## 幻灯片14：附录 - 关键测试结果摘要

### 错别字检测优化前后对比

| 指标 | 优化前（基础版） | 优化后（双模型） | 提升幅度 |
|------|----------------|----------------|---------|
| 准确率 | 89.2% | 92.5% | +3.3个百分点 |
| 召回率 | 42.8% | 85.6% | +42.8个百分点 |
| F1值 | 57.6% | 88.9% | +31.3个百分点 |
| 漏检率 | 57.2% | 14.4% | -42.8个百分点 |

### 优化策略详解
1. **双模型融合**：macbert_finetuned深度学习模型 + pycorrector规则引擎
2. **阈值调优**：检测阈值从0.8降至0.5，提高模型敏感性
3. **规则增强**：添加150+常见错别字规则库
4. **专业术语保护**：避免误改AI领域专业术语
5. **参数化配置**：支持命令行参数调整（阈值、样本数、模型路径）

### 优化效果分析
- **召回率大幅提升**：从42.8%提升至85.6%，有效减少漏检
- **准确率略有提升**：从89.2%提升至92.5%，保持较高精确性
- **F1值显著改善**：从57.6%提升至88.9%，综合性能大幅提升
- **漏检率显著降低**：从57.2%降至14.4%，检测能力显著增强
